My technical background started with strong problem-solving fundamentals in **C++ and Python** alongside building standalone ML workflows. * **Cloud Platforms:** Google Cloud Platform (GCP) & Amazon Web Services (AWS)

## 6-Month Internship Goals

My primary objective over the next six months is to grow into a reliable, production-ready Data Engineer and earn a **Full-Time Offer (PPO)** with the team by demonstrating consistent ownership, clean engineering practices, and measurable delivery impact.

### 1. Master Cloud & Linux Fundamentals

* Build fluency in **Linux** CLI, shell scripting, permissions, and server-side debugging.

* Develop strong working proficiency across core **GCP** and **AWS** data, compute, storage, and IAM services.

### 2. Transition from Scripts to Production Data Foundations

* Move beyond ad-hoc Python/ML scripts toward modular, maintainable, and automated data pipelines.

* Understand best practices around data ingestion, schema design, data quality validation, and preparing clean, reliable datasets for downstream analytics and AI workloads.

### 3. Deliver Value & Earn Full-Time Conversion

* Actively seek feedback, iterate quickly on code reviews, and maintain clear documentation across all assigned tasks.

* Progress from guided onboarding exercises to owning end-to-end features or client-ready deliverables within the team.
